Cheker per Windows

Una finestra per analizzare documenti, leggere i risultati e consultare i contatori. I file sono elaborati dal motore Linux locale tramite WSL 2.

Aprire il programma

  1. Estrai tutto lo ZIP in una cartella scrivibile, per esempio D:\Cheker\app\windows. Conserva insieme EXE, DLL e cartella linux.
  2. Fai doppio clic su Cheker.exe. Al primo avvio il programma prepara il motore: serve Internet per scaricare le dipendenze Python con le versioni fissate nel pacchetto.
  3. Quando compare la dashboard, apri File e scegli i documenti dal tuo computer. Non occorre copiare un token.

Chiudendo la finestra si arresta il suo motore. Le analisi rimangono nella cartella data-linux del pacchetto. L'app Windows usa dati separati dall'app Linux già installata e dalle altre anteprime.

Se è il primo utilizzo di WSL

Requisiti: Windows x64 con WSL 2, una distribuzione Linux configurata, Python 3.11 o successivo con python3-venv, .NET Framework 4.8 e Microsoft Edge WebView2 Runtime.

  1. Segui la guida Microsoft per installare WSL. Per Debian, il comando Windows è wsl --install -d Debian. Il sistema può richiedere autorizzazione amministratore e riavvio.
  2. Apri Debian almeno una volta e completa la creazione dell'utente. Nella sua finestra installa Python: sudo apt update && sudo apt install python3 python3-venv. Controlla con python3 --version che sia almeno 3.11.
  3. Imposta la distribuzione scelta come predefinita: wsl --set-default Debian. Il launcher usa la distribuzione predefinita.
  4. Se manca WebView2, installa Microsoft Edge WebView2 Runtime.
  5. Riapri Cheker.exe.

File e risultati

PDF, DOCX, TXT e Markdown hanno un supporto con limiti espliciti. I formati non supportati, i PDF che richiedono OCR e i contenuti non completamente ispezionabili vengono bloccati. DOC, XLS e XLSX non sono ancora analizzati: non interpretarli come file validi. Nessun rilevatore può garantire di riconoscere ogni attacco.

Per sorvegliare una cartella usa il suo percorso Linux: per esempio D:\Documenti corrisponde normalmente a /mnt/d/Documenti. Il selettore per caricare singoli file funziona direttamente con le cartelle Windows.

Problemi di avvio

  • Il motore non risponde: apri la distribuzione WSL e verifica Python. Per aggiornare WSL usa wsl --update.
  • Windows non raggiunge WSL: consulta la guida Microsoft al collegamento localhost. Cheker non espone il servizio sulla rete.
  • Pacchetto spostato dopo il primo avvio: estrai una nuova copia dello ZIP nella destinazione finale. Le virtualenv Python non sono trasferibili. Con tutte le finestre chiuse puoi trasferire l'intera cartella data-linux nella nuova copia, mantenendo un backup.
  • Log: logs/installazione.log e logs/servizio.log. Conserva questi file localmente e controllane il contenuto prima di condividerli.
Questa distribuzione EXE non dispone ancora di firma Authenticode. Gli hash del manifesto permettono il confronto dei file, ma non sostituiscono una firma dell'editore. Windows può mostrare un avviso per un'applicazione non riconosciuta.
